Demo

One lot, three ways: the site, the command line, this UI

Each run picks an auction that is live on PropertyRoom at that moment, then runs five fixed lots. For every lot you get three views of the same run: what the listing says on the site, what the command line prints, and what this UI shows. Ended lots are also run "as if live", where only the "Ended" line is changed to "Ends". Nothing is bid.

Two limits, and a bid plan must clear both: $4,999.99 is the most any single transaction can cost all-in — PropertyRoom's card and PayPal ceiling — and $2,000 is the most this demo session may spend in total. One of the five fixed lots below, the reflective trailer tape, is a lot the agent would bid on, so the demo shows what a bid plan looks like instead of only ever saying no.
