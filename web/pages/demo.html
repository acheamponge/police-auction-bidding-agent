Demo

One lot, three ways: the site, the command line, this UI

Each run picks an auction that is live on PropertyRoom at that moment, then runs four fixed lots that have ended. For every lot you get three views of the same run: what the listing says on the site, what the command line prints, and what this UI shows. Ended lots are also run "as if live", where only the "Ended" line is changed to "Ends". Nothing is bid.
